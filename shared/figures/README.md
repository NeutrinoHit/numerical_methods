# Рисунки

Рисунки, полученные в проекте, создаются воспроизводимыми скриптами и
сохраняются в `generated/` (в Git не хранятся, кроме `.gitkeep`). Скрипт, из
которого строится рисунок, лежит рядом с материалом или в `shared/code/`.
Внешние рисунки допускаются только с указанием автора, источника и лицензии.
