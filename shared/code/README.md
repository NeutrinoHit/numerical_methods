# Общий код курса

Здесь хранится код, который используется более чем в одной лекции:
референсные реализации методов (LU/Холецкий/SVD, FFT-солверы, схемы для
уравнений теплопроводности и переноса и т. д.), тестовые задачи с
известным аналитическим решением и вспомогательные функции построения
рисунков.

Правила:

- каждая функция проверяется на задаче с известным ответом;
- результаты, зависящие от генератора случайных чисел, получают явный `seed`;
- LightHit подключается как внешний пакет и не копируется в курс.
